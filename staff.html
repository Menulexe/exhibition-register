Print & branding settings

A logo uploaded here changes only this laptop. To use one logo on every laptop, put logo.png in the GitHub repository and set logo: "logo.png" in the code.

In the print window, set Margins to "Default" and turn off "Headers and footers" so these margins apply.

Many inkjets (for example Canon G1030) have no A6 paper size. Pick the paper size the printer does offer (A5 or 4 x 6 in), then use "Card from left / top" to say where your card sits on that paper. 0 and 0 means the card fills the paper.

Drag the three orange boxes onto the card, or type exact numbers below (millimetres from the top-left corner of the card).

Chrome print window: set Paper size to 4 x 6 in (10 x 15 cm), Margins to None, Scale 100, and Color to Black and white. The preview page must be the same shape as the card with the name visible in the white band.

The alignment grid prints a ruler (numbers are mm) with the three boxes. Print it on a spare card, hold it to the light against the real card, and read off the numbers to move the boxes.

Removes every registration (online and walk-in) and the whole pre-registered list from Firebase, for every laptop. A CSV copy is downloaded to this computer first. Your print settings are kept.

Pre-registered list (upload from Excel)

Upload an Excel (.xlsx) or CSV file. The first row must have headings such as Name, Email, Phone, Company, Designation (only Name is required; First name + Last name also work). Format the phone column as Text so leading zeros are kept. People already in the list are skipped, so you can upload again to add more.

Click the name, designation or company on the badge to change it. Changes affect the printed badge only, not the saved list.
